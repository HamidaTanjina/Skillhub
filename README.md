# 🌐 SkillHub

**SkillHub** is a web-based skill exchange platform that connects people who want to share their knowledge and learn new skills through **peer-to-peer learning and skill exchange**.

## 🌐 Live Demo

🚀 [**Visit SkillHub**](https://skillhub-fawn.vercel.app/)

## ✨ Features

* 👤 User registration & authentication
* 📝 User profile management
* 🎯 Teaching and learning skill management
* 🔍 Skill browsing and user discovery
* 🤝 Suggested skill partners
* 📩 Skill exchange requests
* 🔔 Real-time activity notifications
* 💬 Real-time chat between exchange partners
* ⭐ Ratings and reviews
* 📊 User dashboard
* 🌙 Dark and light mode

## 🛠️ Technologies

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Real-Time Communication:** Socket.IO
* **Authentication:** JWT, bcrypt
* **Deployment:** Vercel (frontend), Render (backend)

## 🚀 Local Setup

1. Clone the repository:

```bash
git clone https://github.com/HamidaTanjina/Skillhub.git
```

2. Navigate to the project directory:

```bash
cd Skillhub
```

3. Install backend dependencies:

```bash
cd server
npm install
```

4. Configure the required environment variables in a `.env` file.

5. Start the backend server using the configured npm start script.

6. Open the frontend using a local development server.
